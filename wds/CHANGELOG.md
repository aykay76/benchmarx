# Changelog

## 0.1.0 — initial release

- Design tokens: color (light/dark), spacing, typography, radius, shadow, motion, z-index.
- Base: reset, typography, layout utilities.
- Icon set (`<wds-icon>`) with ~28 common glyphs.
- Components: button, forms, badge, avatar, card/stat-card, list, empty
  state, skeleton, accordion, tabs, modal, drawer, toast, confirm dialog,
  dropdown menu, tooltip, table (sort/select enhancer), tree, navigation
  (app shell + breadcrumbs), pagination, resource panel.
- Docs/style-guide site at `docs/index.html`.
